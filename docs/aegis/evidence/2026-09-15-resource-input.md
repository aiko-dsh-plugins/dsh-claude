# Explicit reference context in native conversation

The adapter accepts the newest direct human input plus its following native `session-reference` messages and `aiko-dsh-workbench-kit` plugin snapshots. Native Session selection works without the kit; shared resource selection retains the kit's version pins and provider checks. Both use DSH's logged, read-only context, preserving warnings and omission notices without appending snapshot JSON to the human bubble. The adapter does not reread referenced sessions, duplicate their storage, or forward general DSH policies, tools or conversation history into Claude's engine.

Adapter tests capture the outgoing supervisor prompt, mix both reference sources in either logged order, exclude old and unrelated contexts, stop association at assistant history, and preserve image order. The integration snapshot runs DSH's native mention pre-step against real in-memory Session events, logs the accepted messages, reads their projected surface, and captures the Claude request. It verifies source prose arrives, source reasoning and injected context are excluded, the direct message keeps its identity and readable label, and the next turn does not resend old snapshots. The paired kit verifies unchanged human content, source-tagged admission and reproducible context. This evidence does not claim a real model request or browser screenshot.
